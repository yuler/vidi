# Vidi 决策树与事实

> 本文记录 2026-08 逐轮讨论锁定的决策与实地探查的事实，供实现时对照，避免反复。决策沿用 grilling 流程：前置已定 → 问当前 frontier → 锁定后推进。

## 实地探查事实（`/Volumes/ToshibaSSD/英语资料`）

| 项 | 事实 |
|---|---|
| 根目录 | `/Volumes/ToshibaSSD/英语资料`，已挂载可访问 |
| 课程数 | 6 个顶层目录 |
| 真实 mp4 | **745 个**（此前统计 1486 是把 `._*` 误算进去） |
| 总量 | 117.28 GiB（125,931,547,509 字节） |
| 嵌套 | 课程 1–5 扁平（mp4 直放）；课程 6 三层（`课程6/雪梨老师读绘本1-6/video.mp4`），共 164 集 |
| 非视频子目录 | 课程1`课程资料/`、课程2`送PDF课件资料/`、课程4`讲义/`（含 70 mp3、5 PDF） |
| 脏文件 | `._*` 820 个；`*.downloading` 4 个（均在课程1，有完成版孪生）；无 `.DS_Store` |
| `(1).mp4` 孪生 | 64 个，全在课程1，疑似内容重复 |
| 特殊字符 | 空格（934 路径）、`[]`（24）、`()`（142）、全角标点、`'`、`~`、`...`；1 个大写 `.MP4` |
| 重名 | basename 完全相同的 mp4 为 0（全部唯一） |
| 编码（抽查3） | 全部 MP4 + H.264 + AAC（720p/1080p，25–30fps）；最大 931MB/27.5min |
| 结论 | **iPad Safari 直通播放，无需转码管线**（research 的最大不确定项退役） |

## 决策树（最终）

### 根决策

| # | 决策 | 结论 |
|---|---|---|
| D0 | 自研 vs 现成方案 | **自研 Vidi**（Jellyfin 太重、AList 缺进度、filebrowser 停维护） |
| D1 | 技术栈 | **Nuxt 4 全栈 + Tailwind v4 + shadcn-vue（reka-ui 底层）**，inspira-ui 按需 |
| D2 | 视频流 | 手写 Range（206/Content-Range/HEAD），H.264 直通 |
| D3 | 进度存储 | `progress.json` 防抖写盘，无数据库 |
| D4 | 常驻 | launchd 用户态 LaunchAgent，端口 8080 |
| D5 | 安全 | 局域网无鉴权、无 PIN；暴露公网才加认证 |

### 目录与内容

| # | 决策 | 结论 |
|---|---|---|
| D10 | 嵌套模型 | ≤3 级：课程 → group → 视频；group 仅在存在子目录时出现 |
| D11 | 超 3 级 | 不丢弃，归入其第 3 级 group，扫描警告"发现 N 个超过3级的文件" |
| D12 | mp3 | 收录，`<video>` 原生播放并标记为音频；PDF 不进目录 |
| D13 | 多根目录 | `settings.json` 存数组，设置页可增删；课程合并展示 + 来源徽标；slug 加目录前缀防重名 |
| D14 | 重复文件 | `(1)` 孪生全展示不删，扫描警告提示家长自行整理源盘 |
| D15 | 排序 | `Intl.Collator('zh-Hans-CN', { numeric: true })` 排课程与集名 |
| D16 | 显示名 | 课程去前导 `N.` 前缀 + trim（副标题"共N集"）；集名去扩展名 + trim 尾部空格，序号保留 |
| D17 | 脏文件过滤 | 忽略 `._*`、`*.downloading`、隐藏文件 |

### 扫描与缓存

| # | 决策 | 结论 |
|---|---|---|
| D20 | 触发 | 首次启动自动扫落盘 `courses.json` 索引；按目录节点 mtime 校验增量重扫；设置页手动全量重扫按钮 |
| D21 | 索引内容 | 每个视频记录路径 + mtime；目录节点级 mtime 校验能捕获深层新增 |

### 首页与播放

| # | 决策 | 结论 |
|---|---|---|
| D30 | 首页 | 顶部"继续观看"（`updatedAt` 倒序、未看完 6 条）+ 课程卡片 |
| D31 | 播放交互 | 点击视频卡片直接全屏（iOS 原生）；0.5–2x 倍速 |
| D32 | 自动连播 | 默认关（设置页开）；按课程排序跨 group 连播；跳集标题提示 2 秒；课程末尾自然停 |

### 进度

| # | 决策 | 结论 |
|---|---|---|
| D40 | 存储字段 | `{ position, duration, updatedAt }`，key 为视频相对路径 |
| D41 | 看完判定 | `position ≥ 95%` 或距末尾 `< 5s` 视为看完 |
| D42 | 上报节奏 | 客户端 5s 节流 + `visibilitychange`/`beforeunload` 强制 flush |
| D43 | 服务端写盘 | 1s 防抖合并，last-write-wins（容多设备并发与快速拖拽） |
| D44 | 原子写 | 临时文件 + rename，防 `progress.json` 写半截 |

### 流边界

| # | 决策 | 结论 |
|---|---|---|
| D50 | MIME | 扩展名小写映射（含 `.MP4` 大写） |
